# Week 3 — Command Line, Git & GitHub

## Overview

This repository contains my Week 3 coursework for the IYF Weekend Academy Season 12. It builds on my Week 2 portfolio and documents my practice with command-line tools, Bash scripting, Git, and GitHub.

## Learning Objectives

- Navigate directories and manage files using the command line.
- Create, copy, move, rename, and remove files and directories.
- Search for files and inspect file contents using terminal commands.
- Write and execute a Bash script to generate a project structure.
- Track changes with Git and write meaningful commit messages.
- Create branches, merge changes, and resolve merge conflicts.
- Use `.gitignore` to exclude unnecessary files from version control.
- Practise collaborative development using GitHub pull requests.

## Project Contents

- `index.html` — portfolio homepage.
- `about.html` — about page.
- `projects.html` — projects page.
- `contact.html` — contact page.
- `styles.css` — portfolio styles, if present under this filename.
- `new-project.sh` — script that generates a standard project structure.
- `terminal-log.md` — record of terminal commands used during the exercises.
- `.gitignore` — rules for excluding files from version control.

## Bash Project Generator

The `new-project.sh` script creates a project directory with starter files and folders.

To use it, run the following command from the repository directory:

```bash
bash new-project.sh my-awesome-app
```

Replace `my-awesome-app` with your preferred project name.

## Skills Practised

### Command Line
- Directory navigation and filesystem management.
- File searching, text searching, and command history.
- Bash scripting and directory automation.

### Git and GitHub
- Repository tracking and meaningful commits.
- Branch creation and merging.
